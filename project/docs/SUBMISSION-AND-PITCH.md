## Two-minute demo outline

1. **Problem:** “Business rules are buried in legacy code. A direct translation can preserve a mistake.”
2. **User:** Introduce the fictional operations analyst who understands policy but not COBOL.
3. **Review:** Load the banking fixture. Show the source, policy, and extracted rule explaining the student-waiver issue.
4. **Decision:** Edit or approve the intended waiver rule. Show that the approved specification controls generation.
5. **Evidence:** Compare the code and show the student case changing intentionally, with other cases preserved. State exactly what was executed and what was precomputed.
6. **Breadth:** If ready, briefly switch to the retail PL/SQL → MySQL example.
7. **Next step:** Explain the buyer hypothesis and a future company-controlled deployment; distinguish it from the current prototype.
